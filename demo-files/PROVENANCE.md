# ARIA 합성 예제 출처·공개 범위

최종 업데이트: 2026-07-24

이 폴더의 연구실, 인물, 날짜, 문서번호, Run ID, 내부 경로, 시약 lot와
실험 결과는 ARIA의 기능 확인을 위해 구성한 합성 시연 데이터입니다. 실제
개인·연구실·시료·환자·피험자 또는 실제 연구결과를 나타내지 않습니다.

> 소프트웨어 평가에만 사용하세요. 실제 실험, 안전 판단, 임상·연구 기록,
> 품질 시스템 또는 공식 SOP로 사용하지 마세요.

| 파일 | 제작·출처 | 공개 범위 |
| --- | --- | --- |
| `transfer-handover-transcript.txt` | 합성 시연 대본의 텍스트 전사문 | 공개 가능. 실제 음성 파일이 아닙니다. |
| `latest-direct-note.txt` | 합성 실행 메모 | 등장 인물, 연구실, 날짜·Run ID·경로·lot·결과는 가상입니다. |
| `troubleshooting-experience.md` | 합성 troubleshooting 기록 | 등장 인물과 날짜는 가상입니다. 실제 실험 지침으로 사용하지 않습니다. |
| `neural-systems-lab-reference-protocol.pdf` | 실제 프로토콜 형식을 참고해 생성한 합성 예시 PDF | 작성자·검토자·승인자·문서번호와 경로는 가상입니다. |
| `handwritten-transfer-note.png` | OpenAI 이미지 생성 도구로 만든 AI 생성 손글씨 시연 이미지 | 이미지의 이름, 날짜, lot와 결과는 가상이며 C2PA 출처 정보를 보존합니다. |

공개 저장소에는 사람 목소리가 담긴 `transfer-handover-recording.m4a`를
포함하지 않습니다. 실제 음성을 공개하려면 화자의 공개 동의를 별도로
기록하거나 합성 음성으로 교체하세요.

이 문서가 파일과 분리되면 합성 자료라는 맥락을 잃을 수 있으므로 자료를
전달할 때 항상 함께 포함하세요.
