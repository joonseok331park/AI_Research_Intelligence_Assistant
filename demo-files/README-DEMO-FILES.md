# ARIA 공개 안전 예제 파일

다음 5개 합성 자료를 `새 프로토콜 만들기` 화면에 한 번에 첨부합니다.

1. `transfer-handover-transcript.txt` — 음성 인수인계를 대신하는 합성 전사문
2. `handwritten-transfer-note.png` — AI 생성 수기 실험 노트
3. `neural-systems-lab-reference-protocol.pdf` — 합성 참고 프로토콜
4. `troubleshooting-experience.md` — 합성 문제 해결 기록
5. `latest-direct-note.txt` — 합성 최신 직접 지시 메모

공개 저장소와 내려받기 ZIP에는 사람 목소리가 담긴 녹음 파일을 넣지
않습니다. 음성 전사 기능을 시험하려면 루트의 `RECORDING_SCRIPT.md`를
본인이 직접 읽어 녹음하거나 공개 동의를 받은 음성만 사용하세요.

모든 인물, 연구실, 날짜, 문서번호, 시약 lot와 결과는 기능 확인용 가상
정보입니다. 실제 실험이나 안전 판단에 사용하지 마세요. 자세한 출처와
공개 범위는 `PROVENANCE.md`를 확인하세요.
